A launcher bar for Windows and macOS. Summon it over any app and type to open an app, a setting, a file or a link, or search Google.

## Download

- **[Stable](https://github.com/z3k-md/zephyr/releases/latest)**: the latest release.
- **[Nightly](https://github.com/z3k-md/zephyr/releases/tag/nightly)**: built from `develop` each night it changes. That page links the newest nightly build.

Grab `-setup.exe` for Windows or `.dmg` for macOS (Apple silicon). First launch: [install guide](https://z3k-md.github.io/zephyr/guide/install).
