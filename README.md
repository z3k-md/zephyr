A launcher bar for Windows and macOS. Summon it over any app and type to open an app, a setting, a file or a link, or search Google.

## Download

Get the latest build from [Releases](https://github.com/z3k-md/zephyr/releases/latest): the Windows `-setup.exe` or the macOS Apple silicon `.dmg`. See the [install guide](https://z3k-md.github.io/zephyr/guide/install) for SmartScreen and first launch on macOS.
